隐私政策

本政策说明 DeviceCue 如何处理账号、设备认证、社区、反馈及支持请求中的信息，以及你可以如何管理这些信息。

生效日期：2026 年 10 月 4 日。适用版本：DeviceCue 1.0。

运营者与适用范围

DeviceCue 由质感工场（杭州）科技有限公司运营及发行。你可以查看设备资料和认证持有人数、比较候选、提交设备认证、参与同款讨论，以及保存和同步想买清单。本政策也适用于 App 内反馈、支持邮件及 DeviceCue 支持网站。

首发面向美国、加拿大、英国、澳大利亚及新西兰的一般设备用户，实际供应地区以 App Store 为准。支持、设备认证、社区审核、举报及个人信息请求由运营者人工处理。

联系邮箱：developer@txturefty.com。使用本邮箱可以咨询、复核处理结果或提出个人信息请求；无法登录 App 时也可以联系。

处理哪些信息，为什么需要

Apple 账号标识、邮箱及登录会话
选择使用 Apple 登录时，我们处理 Apple 提供的账号标识、你授权提供的邮箱（可能为隐藏邮箱的中继地址）、身份凭证和必要会话信息，用于建立、验证和保护账号、同步数据，以及在删除账号时处理已保存的 Apple 授权凭据。当前登录只请求邮箱，不主动请求姓名。授权码交换及可撤销凭证由服务端处理。
想买清单与同步记录
候选设备标识、加入或移出操作，以及防止重复处理所需的同步记录和回执与账号关联，通过 Supabase 保存并同步到同一账号的设备。清单不向其他用户公开；未得到云端确认的操作仍显示待同步。
设备记录与认证照片
你提交的设备实拍、型号、可选说明及审核状态与账号关联，用于人工核验设备持有情况和处理复核请求。照片保存在私有空间，不公开展示。公开人数按已认证的账号和型号去重；待审核、未通过及正在移除的记录不计入人数。没有使用 AI 审核。
社区话题、回复、举报及屏蔽
话题和回复与账号关联，审核通过后以独立社区标识及系统称呼公开，不展示 Apple 邮箱。待审核或未通过的原文及审核说明仅本人和负责处理的服务可见。举报原因、说明和屏蔽关系用于内容处置及个人展示，不向被举报者公开。运营者人工审核和处理举报。
App 内反馈
反馈不要求登录，也不主动关联 Apple 账号。提交时会发送正文、你自愿填写的联系邮箱、App 版本及构建号、系统版本、语言与地区设置，以及随机提交编号；服务端记录接收时间和回执编号。这些信息用于排查问题、改进功能、防止重复提交及在你提供邮箱时联系你。反馈不公开。正文和邮箱可能包含个人信息，请只提供必要内容。
支持邮件
通过邮箱联系时，我们处理你提供的联系方式、问题描述、附件及后续往来，用于回复、排查和处理权利请求。发送截图前请遮住无关个人信息。
必要的网络与服务日志
网站和在线服务的网络层会收到 IP 地址、请求时间、请求路径、状态及必要错误信息，用于传输、服务运行和安全排查。反馈业务表不保存 IP 地址或 IP 哈希；限流使用全局计数。服务提供方的网络及运行日志独立于反馈记录。

本版不提供广告或行为分析功能，不使用反馈进行广告定向。浏览公开资料、比较设备及提交反馈无需登录；设备认证、发表社区内容、想买清单和跨设备同步需要账号。

本机保存、权限与外部资料

App 在设备上保存可用产品资料、账号会话、该账号的清单缓存及尚未成功同步的操作。本机清单按账号分别保存；退出登录后该账号的清单隐藏，再次登录同一账号可以继续读取或重试同步。卸载 App、丢失或损坏设备后，未上传的修改无法从云端恢复。

仅在你主动拍摄设备认证照片时请求相机权限。上传前重新生成图片，移除原始照片的位置等元数据；无需访问相册、通讯录、位置或麦克风。关闭 App 只会清理本机照片临时内容。已上传但记录提交失败的照片可能仍在私有存储中，可通过支持邮箱请求清理；成功删除账号时也会处理该账号的认证照片。

点击产品资料来源后，你会访问由其各自运营者提供的第三方网站，请阅读对方的数据处理说明。DeviceCue 的帮助与隐私页面为静态页面，不包含分析脚本、网页反馈表单、跟踪工具或自动加载的第三方资源；GitHub Pages 仍会处理下文所述的网站访问信息。

服务提供方与处理地点

Apple
提供“通过 Apple 登录”，处理身份验证及相关授权。其自身服务适用 Apple 隐私政策。
Supabase
提供账号认证、数据库、私有照片存储和服务端函数，包括清单、设备记录、社区及反馈。项目主数据区域为新加坡；函数可能在靠近请求者的区域运行，服务日志及恢复处理遵循供应商安排，不能理解为所有处理仅限新加坡。参见 Supabase 隐私说明。
GitHub Pages 与 DeviceCue 网站
devicecue.com 的公开资料库、帮助和隐私页面通过 GitHub Pages 托管及分发。GitHub 可能在美国及其自身或服务商运营的其他国家处理服务数据。该静态网站不接收认证照片或反馈正文；这些内容由独立的 Supabase 服务处理。参见 GitHub 隐私声明。
Google Workspace
公司支持邮箱通过 Google Workspace 处理邮件及附件，不将其存储位置限定为某个国家。参见 Google Workspace 安全与隐私说明。

运营者位于中国杭州，可能为支持、人工审核和处理请求访问相关信息。使用在线服务时，信息可能在你所在国家之外处理。服务提供方按各自承担的功能处理相应信息；我们的处理范围受本政策所述目的限制。如需了解或提出相关请求，请联系支持邮箱。

信息保存多久

账号及账号关联数据
账号、清单、设备记录、认证照片、审核说明、社区内容、举报、屏蔽及必要操作回执在相应账号或内容保留期间用于提供功能和复核。删除相关内容或账号时，按下节所述流程处理关联数据。会话及授权凭据仅用于登录与账号管理；未完成的本机同步操作保留供重试。
App 内反馈
反馈正文、可选邮箱、版本和系统信息、语言与地区设置、提交及回执编号保存 180 天，并在下一次每日清理时从反馈数据库删除。你也可以凭反馈编号提前申请删除。反馈未关联账号，删除账号不会自动删除反馈。
支持邮件及附件
处理请求期间保留必要往来；请求处理结束后 180 天内清理。你可以联系支持邮箱申请提前删除。需要核实尚未解决的请求时，我们会说明仍需保留的信息和原因。
网站访问信息
GitHub Pages 会为安全目的记录和保存访客 IP 地址，无论访客是否登录 GitHub。GitHub 还依其隐私声明处理请求和服务信息；保存时间取决于处理目的和适用要求，我们不承诺固定的网站日志保留期限。我们不自行保存逐条网站访问日志，也不能直接控制 GitHub 平台日志中的单条记录。这些记录与 Supabase 中的反馈数据相互独立。参见 GitHub Pages 数据收集说明及 GitHub 保存安排。
供应商日志和恢复副本
当前 Supabase 免费计划向我们提供约 1 天的 API 和数据库日志可访问记录，不包含向我们提供的自动数据库备份。这不代表所有供应商内部日志或恢复副本会在 24 小时内永久清除。供应商为服务运行、安全或恢复保留的记录按其流程管理，不能由 App 逐项即时擦除。

数据删除以实际成功结果为准，不承诺所有系统、离线设备和恢复副本同时立即抹除。

删除账号与关联数据

打开 App“设置”，选择“删除账号与数据”，阅读提示后确认“永久删除账号与数据”。删除不可撤回；退出登录或卸载 App 不等于删除云端账号。

删除流程处理云端账号、清单、设备记录及认证照片，撤销服务端已保存的 Apple 授权凭据，并清理当前设备关联的会话和账号缓存。请按 App 提示在系统设置“Apple 账号 → 通过 Apple 登录”中检查并停止使用本 App；其他设备可能产生的授权也需核对。

删除账号还会删除你发表的话题和回复、社区标识、本人提交的举报与屏蔽记录。删除话题会一起删除全部回复，包括其他用户的回复；删除单条回复不影响其他回复。删除的内容不再公开。

删除失败或结果未确认时，App 显示错误或“账号删除尚未完成”，暂停相关同步与修改，并保留重试入口。请等待明确成功结果，不要把提交请求视为已删除。无法登录或持续失败时，可通过支持邮箱申请协助。

你也可以在“我的设备”单独移除设备记录及认证照片；移除开始后不再计入人数，照片清理失败时可重试。其他离线设备需联网确认后清理本机缓存，也可卸载 App 清除该设备的缓存。当前设备清理失败时，选择“重试清理此设备的数据”。

App 内反馈不关联账号，请另向支持邮箱提供反馈编号申请删除；不必为此提供 Apple 登录凭据。服务日志、邮件和恢复副本按上述保存安排处理。

个人信息权利与联系方法

你可以按适用法律提出查询、复制、更正、补充或删除个人信息、撤回同意，或要求说明处理方式。清单修改、内容移除和账号删除可从 App 内发起；其他请求或对处理结果有异议时，请联系 developer@txturefty.com，说明请求及相关账号、内容或反馈编号。

运营者人工受理请求，必要时只核对与请求风险相称的信息，以防止他人取得或删除你的资料。请勿发送 Apple 密码、验证码或登录凭据。反馈未填写邮箱时，我们无法主动回复；可凭编号发邮件补充联系方式或申请删除。

我们按适用要求处理请求，并在需要补充信息或无法按请求处理时说明原因。若认为结果有误，可以通过同一邮箱提出复核。

未成年人

DeviceCue 面向一般设备用户，不专门面向儿童。本版没有年龄验证或监护人认证功能。未成年人使用时应遵循适用的年龄和监护要求，避免在照片、公开讨论或反馈中提供不必要的个人信息。

监护人或其他用户发现不适当的未成年人个人信息时，可联系支持邮箱并提供相关内容或反馈编号。我们会核实并处理删除请求，不要求发送与核实无关的敏感资料。

政策更新

数据用途、服务提供方或其他重要处理安排变化时，我们会更新本页及 App 内说明，并在适用时另行告知或取得同意。更新版本会标明生效日期，并保留历史版本。

本政策自 2026 年 10 月 4 日生效。操作说明见使用帮助。
